# TickerPigeon brand assets

A small selection from the TickerPigeon brand pack, the files this repository uses. The name is
spelled **TickerPigeon**, and the mascot is **Pip**, an attentive little news courier.

| File | Use |
|---|---|
| `readme-banner.jpg` | README header (1600×800) |
| `github-social.jpg` | Repository social preview (1280×640). Set it in **Settings → General → Social preview** |
| `logo-light.png`, `logo-light.webp` | Logo for light backgrounds, transparent |
| `pigeon-mark.png` | Compact symbol, transparent (256 px) |
| `avatar.png` | Profile picture for your chat bot, navy (512 px). In Telegram: @BotFather → `/setuserpic` |
| `pip-delivering.webp` | Product introduction |
| `pip-waving.webp` | Welcome and setup |
| `pip-reading.webp` | News and digests |
| `pip-flying.webp` | Delivery |
| `pip-quiet.webp` | Quiet hours, no new stories |
| `brand-tokens.css` | Colour tokens |

The dashboard favicon lives at `pipeline/dashboard/static/favicon.ico`.

## Copy

- Tagline: **Your stocks. Your news. Your chat.**
- Descriptor: **Your personal stock-news messenger.**
- One sentence: **An open-source agent that follows news about the stocks you hold and delivers
  updates to your messaging app.**

## Usage

- Keep artwork at its original aspect ratio.
- Leave clear space around the logo of at least half the bird icon's height.
- Use the transparent navy-lettered logo on light surfaces, and the navy avatar for profile pictures.
- These are raster files; there's no editable vector source.
